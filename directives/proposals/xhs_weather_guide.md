# B1. 날씨 기능 공략 게시물 원고 제안서 (`xhs_weather_guide.md`)

## 1. 기획 의도 및 제약 사항 준수 체크리스트

- **대상 독자**: 제주도 여행을 준비 중이거나 체류 중인 **중국 20·30대 여성** (인생샷, 코디/옷차림, 비·바람으로 인한 일정 망침 방지, 감성 해변 카페 방문에 민감)
- **목적**: 제주 날씨가 왜 일반 날씨 앱과 다른지 설명하고, **지역별 비교 → 시간별 예보 → 주간 예보 → 과거 날씨(월별 실측) → 기상특보·항공편 → 한라산 탐방로** 기능을 100% 활용하는 법을 7장 카드뉴스 형태로 안내
- **샤오홍슈(小红书) 규정 및 제약 사항 준수**:
  - [x] 이미지 내 **도메인(URL), 위챗(微信/WeChat), 홍바오(红包), 바오처(包车)** 등 인류(引流)·상업 키워드 **일절 배제**
  - [x] 광고법 위반 소지가 있는 **최상급 표현(`最`, `第一`, `绝对`, `推荐` 등) 사용 금지**
  - [x] 카드 우측 상단 또는 하단 워터마크로 계정명 **`@济州本地人_正敬`** 만 깔끔하게 표기
  - [x] 각 장은 **제목 1줄 + 본문 2~4줄**로 구성해 모바일(3:4 비율, 1080×1440) 가독성 극대화
  - [x] 마지막 장(7장)에 **댓글 유도 질문** 배치

## 2. 카드별 원고 (총 7장 구성, 3:4 비율 기준)

### 📌 제1장 (표지 / 封面): 왜 제주도 날씨는 동네마다 다를까?
- **역할**: 호기심 유발 + 지역별 비교(济州市·挟才·西归浦·城山) 개념 소개
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 제주도 동·서·남·북 4개 권역(제주시·협재·서귀포·성산) 날씨 요약 카드 화면 클로즈업
- **원고**:
  - **제목**: `济州岛天气怎么看？别只看一个预报`
  - **본문**:
    1. 汉拿山在岛中央挡住云层，经常出现北边下雨、南边出太阳的情况。
    2. 看天气时可以把 **济州市(北)·挟才(西)·西归浦(南)·城山(东)** 四个方向对比着看。
    3. 早上出门前先看哪边晴天、哪边风小，再决定当天去东线还是西线拍照。

---

### 📌 제2장: 비는 몇 시에 그칠까? (시간별 예보 & 야외 적합도)
- **역할**: 실시간/내일 날씨 카드의 '한눈에 보기(户外适宜度)' 배너와 시간별 예보(`hourly-table`) 읽는 법
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: `户外适宜度: 适合/一般` 배너 + 시간별 강수확률(%)·강수량(mm)·풍속(m/s)·일출/일몰 시각 표
- **원고**:
  - **제목**: `几点停雨？看每小时降水和风速`
  - **본문**:
    1. 济州岛很多时候是阵雨，看“每小时预报”能知道几点下雨、几点放晴。
    2. 注意看 **降水量(mm)** 和 **风速(m/s)**：每小时不足1mm带把折叠伞就行；风速超过9m/s去海边头发容易吹乱、伞也会翻。
    3. 表格里还标了日出·日落时间，去咸德、挟才或山房山看日落前可以先算好时间。

---

### 📌 제3장: 일주일 중 언제 바닷가 가고 언제 카페 갈까? (주간 예보)
- **역할**: 10일 주간 예보(`weekly-grid`)와 날짜 클릭 시 시간별 표 연동 기능 안내
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 주간 예보 카드 리스트 + 북부(济州市) vs 남부(西归浦) 기온·강수 비교 화면
- **원고**:
  - **제목**: `一周天气：哪天去海边，哪天逛室内？`
  - **본문**:
    1. 出发前一周先看连续7~10天的晴雨趋势，把晴天留给牛岛、月汀里和涯月海边。
    2. 降水概率高(60%以上)的日子，可以安排美术馆、百货免税店或室内咖啡厅。
    3. 点击周间预报里的具体日期，就能直接跳到那一天的详细时段预报（4天后为中期预报，出发前建议再核对一次）。

### 📌 제4장: 다음 달에 가는데 무슨 옷 챙기지? (과거 날씨 / 월별 실측)
- **역할**: 과거 날씨 탭(`过去天气` / ASOS 관측 실측 달력 및 최근 5년 통계)을 활용한 옷차림 준비법
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 과거 날씨 달력(일별 최고/최저 기온, 비 온 날/맑은 날 통계, 옷차림 팁 박스)
- **원고**:
  - **제목**: `提前一个月订机票，怎么准备穿搭？`
  - **본문**:
    1. 还没到预报期时，可以翻看 **往年同月实测日历（韩国气象厅地面观测）**。
    2. 一眼看出这个月平均最高/最低几度、平均下几天雨、早晚温差有多大。
    3. 比如春秋季早晚温差常在7°以上，适合准备薄针织衫+防风外套的“洋葱式穿搭”。

---

### 📌 제5장: 강풍·풍랑·태풍 때는 비행기와 배가 뜰까? (기상특보)
- **역할**: 기상특보 배너(`气象预警`)와 특보 브리핑(주의보 vs 경보, 제주공항 출발편 결항/지연 현황) 보는 법
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 기상특보 카드(`强风注意报` / `风浪注意报` + 제주 출발 항공편 통계)
- **원고**:
  - **제목**: `遇到强风·风浪预警，航班和船班怎么办？`
  - **본문**:
    1. 气象厅特报分两级：**注意报（提醒级）** 和 **警报（危险级）**，还会标出山地、北部、近海等生效区域。
    2. 出现 **强风特报** 时留意济州机场出发航班延误或取消情况；出现 **风浪特报** 时牛岛、加波岛船班可能停航。
    3. 恶劣天气天尽量避开海岸步道和溪谷，先确认交通状态再出门。

---

### 📌 제6장: 한라산 올라가도 될까? 백록담이 보일까? (한라산 탐방로)
- **역할**: 한라산 5개 주요 코스(어리목·영실·성판악·관음사·돈내코) 실시간 개방/통제 현황 및 CCTV·산악 날씨 안내
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 한라산 탐방로 개방(`正常开放`) / 통제(`全面管制`/`部分管制`) 배지 및 실시간 CCTV 화면
- **원고**:
  - **제목**: `去汉拿山之前，先看登山路开放状态`
  - **본문**:
    1. 就算市区是大晴天，汉拿山山上也可能因为大风、大雨或结冰临时管制。
    2. 出发前先看 **御里牧·灵室·城板岳·观音寺** 等路线的实时开放状态和山顶实时画面。
    3. 山上气温比市区低约6~10°，风也更大，登山记得多带一件防风保暖层。

---

### 📌 제7장 (마무리 & 댓글 유도): 출발 전 날씨 체크 순서 요약
- **역할**: 시기별(출발 한 달 전 → 일주일 전 → 당일 아침) 활용 루틴 요약 + 댓글 참여 유도
- **계정 표기**: `@济州本地人_正敬`
- **시각 레이아웃 제안**: 깔끔한 체크리스트 3단계 박스 + 하단 댓글 유도 말풍선 강조
- **원고**:
  - **제목**: `济州岛看天气3步法，存下来随时查`
  - **본문**:
    1. **出发前1个月**：看往年同月实测气温和雨天数，准备行李和穿搭。
    2. **出发前1周**：看7天晴雨趋势，排好东线、西线和南线行程。
    3. **当天早上**：对比四个区域实时天气 + 看汉拿山开放状态和气象特报。
  - **댓글 유도 질문 (하단 고정 박스)**:
    > 💬 **几号来济州？准备去哪条线？评论区留日期，帮你看天气和穿搭！**
