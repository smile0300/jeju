# Gemini 디엔핑 매칭 프롬프트 (중국어 상호·링크 수집)

대상: 맛집(BETA) `src/data/eats.js` 중 **중국어 후기 '있음' 159곳** (식당 95 · 카페 64). 구글 리뷰 많은 순으로 27곳씩 6묶음.
목적: 중국인 손님이 실제로 검색하는 **중국어 상호**와 **大众点评 링크**를 붙여 맛집 카드에 표시.
번호 `E{id}`는 현재 `src/data/eats.js`의 `id`. 데이터를 다시 만들면 번호가 바뀔 수 있으니 반영할 때는 **이름+주소**로 맞출 것.

## 원칙

- **가져오는 것**: 중국어 상호, 가게 링크, 인당 가격(人均), 디엔핑에 쓰인 대표 메뉴 중국어 이름 — 사실 정보만.
- **가져오지 않는 것**: 후기 문장, 사진, 디엔핑 평점·순위. (화면에서는 링크로 넘긴다)
- **자동 수집 금지**: 한 곳씩 검색해서 확인. 디엔핑이 로그인을 요구하거나 막히면 携程(Trip.com) 맛집 페이지, 그다음 小红书 검색 결과에서 상호를 찾고 출처 칸에 적는다.
- 추측 금지: 같은 가게라는 근거(주소·전화·한국어 병기 상호)가 없으면 "확인불가".
- 결과는 `directives/proposals/restaurants_dianping.md`에 묶음별로 누적. Claude Code에서 확인 후 `tools/build_eats_data.js`에 반영.

## 프롬프트 (묶음마다 {LIST}만 바꿔 넣기)

```
아래 제주 식당·카페를 大众点评(dianping.com)에서 하나씩 찾아서 표로 정리해 줘.

찾는 방법
- 한국어 상호로 먼저 검색하고, 안 나오면 지역명(济州/西归浦/城山/涯月 등) + 음식 종류로 검색.
- 디엔핑 상호에는 한국어가 괄호로 함께 적힌 경우가 많다. 예: 明珍鲍鱼(명진전복)
- 반드시 주소·전화번호·한국어 병기 상호 중 하나 이상이 일치해야 같은 가게로 본다. 체인의 다른 지점과 섞지 말 것.
- 디엔핑에 없거나 접속이 막히면 携程(Trip.com) 맛집 페이지, 그다음 小红书에서 찾고 "출처" 칸에 적을 것.
- 못 찾았거나 확실하지 않으면 추측하지 말고 "확인불가"라고 쓸 것.

가져오지 말 것: 후기 문장, 사진, 평점·순위.

표 열 (이 순서 그대로, 표 하나만 출력, 표 앞뒤 설명 금지, 셀 안 줄바꿈 금지):
번호 | 한국어 이름 | 중국어 상호 | 출처 | 링크 | 人均(¥) | 대표메뉴(중국어) | 일치근거 | 비고

- 중국어 상호: 사이트에 적힌 그대로 (괄호 속 한국어는 빼고 중국어 부분만)
- 출처: 大众点评 / 携程 / 小红书 / 확인불가
- 링크: 가게 상세 페이지 주소 (검색 결과 페이지 말고)
- 人均(¥): 숫자만, 없으면 빈칸
- 대표메뉴(중국어): 디엔핑·携程에 나오는 메뉴 이름 1~3개, 쉼표로 구분
- 일치근거: 주소 / 전화 / 한국어병기 중 확인한 것
- 비고: 지점 혼동 가능, 이전, 상호 변경 등 특이사항만 짧게

목록 (번호. 이름 | 지역 | 주소 | 전화):
{LIST}
```

## 반영 계획 (Claude Code)

1. 결과 검토: 일치근거가 비었거나 체인 지점이 의심되는 줄은 직접 확인.
2. `src/data/eats.js`에 `zh`(중국어 상호) · `dp`(링크) · `zs`(출처) 필드 추가.
3. 카드: 중국어 화면에서 중국어 상호를 크게, 한국어 이름을 작게. 링크가 있으면 '大众点评' 버튼 추가. 검색도 중국어 상호로 되게.
4. 못 찾은 곳은 자체 번역 이름을 붙이고 '자체 번역'으로 구분 (다음 단계).
