# Gemini 맛집 지표 검증 프롬프트 (Claude in Chrome · 구글맵)

대상: 아티팩트 "제주 후보지 선별"의 식당 382곳 (지역별 25~32곳씩 13묶음)
목적: 맛집 필터(평점·리뷰수·가격대·영업상태 등)에 쓸 지표 수집. **Gemini 값은 참고용** — 폐업·평점 이상치는 구글맵/네이버에서 직접 재확인 후 반영.

## 프롬프트 (묶음마다 {LIST}만 바꿔 넣기)

```
구글 지도에서 아래 제주 식당들을 하나씩 찾아서 지표를 표로 정리해 줘.

규칙
- 반드시 구글 지도에서 이름과 주소가 일치하는 장소를 찾을 것. 이름이 비슷한 다른 지점(체인 다른 지점)과 섞지 말 것.
- 못 찾았거나 확실하지 않으면 추측하지 말고 해당 칸에 "확인불가"라고 쓸 것.
- 숫자는 숫자만 (평점 4.3, 리뷰수 1234). 가격대는 구글 지도에 나오는 1인 가격 범위(예: ₩10,000~20,000), 없으면 대표 메뉴 가격으로 추정하고 뒤에 "(메뉴)"라고 붙일 것.
- 영업상태: 영업중 / 임시휴업 / 폐업 / 확인불가 중 하나.
- 표 하나로 출력하고, 표 앞뒤에 설명은 쓰지 말 것. 셀 안에서 줄바꿈 금지.

표 열 (이 순서 그대로):
번호 | 이름 | 구글평점 | 구글리뷰수 | 1인가격대 | 영업상태 | 정기휴무 | 영업시간 | 대표메뉴 | 영어·중국어메뉴 | 1인식사 | 비고

- 영어·중국어메뉴: 리뷰·사진에서 확인되면 "영어", "중국어", "영어+중국어", 안 보이면 "없음"
- 1인식사: 가능 / 2인부터 / 확인불가
- 비고: 이전·상호변경·주소불일치 등 특이사항만 짧게

식당 목록 (번호. 이름 | 주소):
{LIST}
```
