# 제주 로컬 식당 후보 수집 요청

너는 제주 여행 정보 사이트 jeju-live.com의 식당 후보 조사를 맡았다. 이용자는 중국·영어권 자유여행객이고, 대부분 20~30대 여성이다. 사이트의 컨셉은 **"관광객용 식당이 아니라 제주 사람들이 실제로 가는 로컬 식당"**이다.

네가 찾은 결과는 사람이 한 곳씩 검수한 뒤 사이트에 올린다. 그러니 **많이 찾는 것보다 정확한 것이 중요하다.** 확인하지 못한 정보는 지어내지 말고 `확인불가`라고 적어라. 틀린 정보 1개가 빈칸 10개보다 나쁘다.

### 작업 환경 규칙 (반드시 지킬 것)
- 이 작업은 **조사만** 한다. 저장소의 코드·데이터·설정 파일은 하나도 수정하거나 지우지 마라.
- 결과는 `directives/proposals/restaurants_local.md` **한 파일에만** 쓴다. 다른 파일은 만들지 마라.
- 웹페이지는 브라우저로 직접 열어서 확인하라. 검색 결과 요약만 보고 적지 마라.
- **한 번에 다 하지 말고 단계별로 진행하라.**
  1. 0번 타이틀 정리표를 만들어 파일에 쓰고 멈춘다.
  2. 그다음부터는 지역 하나(8곳)씩 조사해서 파일의 CSV에 이어 붙이고, 지역마다 멈춘다.
  3. 순서: north → east → west → south → mid
  4. 다섯 지역이 끝나면 ② 탈락 목록과 ③ 자체 점검을 채운다.
  - 멈출 때마다 "다음 지역 진행할까요?"라고 묻고 지시를 기다린다.

## 0. 먼저 할 일: 식당 타이틀(인증·선정) 조사

식당을 찾기 전에, 제주 식당에 붙는 **공식·준공식 타이틀**을 먼저 조사해서 표로 정리하라. 이 표는 식당을 찾는 출발점이 된다. 각 타이틀의 공식 명단에서 후보를 뽑으면 근거가 확실하다.

조사할 타이틀 예시 (이 밖에도 찾으면 추가):
- 착한가격업소 (행안부·제주도·제주시·서귀포시)
- 백년가게 (중소벤처기업부)
- 제주 향토음식점 지정, 모범음식점, 안심식당
- 블루리본 서베이, 미쉐린 가이드 (빕구르망·셀렉티드)
- 제주관광공사·visitjeju 선정 맛집, 제주도 "도민맛집"류 선정 (공식 명단이 있는 경우만)
- 오래된 가게 지원사업 등 지자체 노포 인증

타이틀마다 아래를 적는다.

| 타이틀 | 주관 기관 | 선정 기준 요약 | 공식 명단 URL | 최신 갱신 연도 | 로컬 신뢰도 |
|---|---|---|---|---|---|

- **로컬 신뢰도**는 `높음` / `보통` / `낮음`으로 적고 이유를 한 줄 붙인다. 예: 착한가격업소는 동네 식당이 많아 `높음`, 미쉐린·블루리본은 관광객도 많이 찾아 `보통`.
- 공식 명단을 찾지 못한 타이틀은 표에 남기되 `공식 명단 URL`에 `확인불가`라고 적고, 그 타이틀만으로는 후보를 뽑지 마라.
- 방송 출연("수요미식회 방영" 등)은 타이틀이 아니다. 근거로 쓰지 마라.

## 2. 수량과 배분

- 지역 5곳 × (트랙 A 4곳 + 트랙 B 4곳) = **총 40곳**
- 같은 지역 안에서 같은 세부유형은 **최대 2곳** (예: 동부에 치킨집 4곳 금지)
- 40곳을 다 못 채우면 채운 만큼만 내라. 기준에 못 미치는 곳으로 숫자를 채우지 마라.

| 코드 | 범위 |
|---|---|

## 3. 로컬 판정 기준

아래 항목 중 **3개 이상** 충족해야 후보가 된다. 충족한 번호와 근거를 `선정근거`에 `번호(근거)` 형식으로 적고, 충족 개수를 `우선순위해당`에 숫자로 적어라.

1. **타이틀 보유**: 0번에서 정리한 타이틀 중 하나 이상 (공식 명단에서 확인된 것만). 가진 타이틀은 전부 `보유타이틀` 칸에도 적는다
2. **업력 10년 이상**: 개업 연도나 "○○년 된" 같은 근거가 있어야 함
3. **입지**: 관광지 상권이 아니라 주거지·마을·오일시장·재래시장 안
4. **도민 단골 후기**: 네이버 블로그·카페에 "도민", "현지인", "단골" 맥락의 후기가 여러 건
5. **도민 고객층**: 이른 아침 영업, 평일 점심 직장인 위주, 포장 손님 위주 등
6. **평점**: 카카오맵 4.0 이상 (평점과 건수를 함께 적기, 예: `카카오맵 4.6/120건`)
7. **(트랙 B만) 중국어권 언급**: 小红书·大众点评·携程에 언급된 글이 있음 → `중국인언급링크`에 URL 필수

예시: `1(제주시 착한가격업소), 2(1998년 개업), 3(이도2동 주거지 골목), 4(도민 단골 블로그 후기 다수)`

## 5. 정확성 규칙

- **링크를 지어내지 마라.** 실제로 열어서 확인한 URL만 적어라. 우선순위는 네이버 플레이스(`https://m.place.naver.com/restaurant/숫자/home`), 그다음 카카오맵(`https://place.map.kakao.com/숫자`), 그다음 visitjeju.net이다. 여러 개면 ` / `로 구분한다.
- `네이버리뷰수`는 확인한 날 기준 **방문자 리뷰 수 숫자만** 적는다. 못 봤으면 `확인불가`.
- 영업시간·휴무·브레이크타임은 출처마다 다를 수 있다. 가장 최근 출처를 따르고, 서로 다르면 `플래그`에 `영업정보 불일치`라고 남겨라.
- 주소는 도로명 주소 전체로 적는다.
- 모든 행에 `확인일`(YYYY-MM-DD)과 `최근리뷰일`(YYYY-MM)을 적는다.

## 6. 중국인 여행객에게 필요한 정보

`우려사항`에는 아래 순서대로 ` / `로 이어서 적어라. 모르는 항목은 `확인불가`라고 적는다.

`메뉴판 언어 / 1인 주문 가능 여부(최소 주문 인분) / 브레이크타임 / 정기휴무 / 주문·결제 방식(키오스크 언어, 선불·후불) / 해외카드·알리페이·위챗페이 / 주차·대중교통 / 대기 상황`

예: `한국어 메뉴판만 있음 / 1인 주문 가능(감자탕 소자) / 브레이크타임 15:00~17:00 / 매주 월요일 휴무 / 자리에서 주문 후 후불 / 해외카드 가능, 알리페이 확인불가 / 매장 앞 주차 3대 / 점심 12시대 10~20분 대기`

---

## 7. 출력 형식

결과는 마크다운 파일 하나로, 아래 네 부분을 순서대로 담아라. 맨 앞에 0번의 **타이틀 정리표**를 넣는다.

### ① 후보 CSV
코드 블록 하나에 담는다. UTF-8, 쉼표로 구분하고 모든 값은 큰따옴표로 감싼다. **헤더는 아래와 글자 하나까지 똑같이** 쓴다.

```
"이름_ko","지역","분류","세부유형","주소_ko","네이버리뷰수","예약필요","예약수단","외국인직접예약","대기시간","중국어후기","사진포인트","우천가능","우선순위해당","선정근거","우려사항","출처링크","규모","우천전용","플래그","트랙","대표메뉴_가격","1인주문","메뉴판언어","결제수단","최근리뷰일","중국인언급링크","보유타이틀","확인일"
```

| 칸 | 넣을 값 |
|---|---|
| 지역 | `north` `east` `west` `south` `mid` 중 하나 |
| 분류 | 항상 `식당` |
| 세부유형 | 대표 메뉴 기준, 짧게 (예: `감자탕`, `접짝뼈국`, `옛날통닭`) |
| 예약필요 | `Y` 또는 `N` |
| 예약수단 | 예: `전화 / 현장 방문`, `캐치테이블 / 현장 대기` |
| 외국인직접예약 | `가능` (현장 방문·전화만으로 충분) 또는 `어려움` (한국 휴대폰 번호가 필요한 앱 예약, 한국어 전화만 받음 등) |
| 대기시간 | 예: `없음`, `없음~15분`, `30분~1시간` |
| 중국어후기 | `있음` 또는 `없음`. `있음`이면 `중국인언급링크` 필수 |
| 사진포인트 | 사진이 잘 나오는 장면 한 줄. 없으면 빈칸 |
| 우천가능 | 항상 `Y` |
| 규모 | `local` (동네 식당, 방문자 리뷰 3,000건 미만) / `small` (작은 매장이지만 관광객 비중이 큼) / `large` (리뷰 3,000건 이상 또는 대형 매장) |
| 우천전용 | 항상 빈칸 |
| 플래그 | 주의할 점. 리뷰 3,000건 이상인 로컬 식당이면 `도민 맛집인데 리뷰 3,000건 이상` |
| 트랙 | `A` 또는 `B` |
| 대표메뉴_가격 | 예: `감자탕 소 28,000원 / 뼈해장국 10,000원` |
| 1인주문 | `가능` / `불가(2인분 이상)` / `확인불가` |
| 메뉴판언어 | 예: `한국어만`, `한국어·영어`, `한국어·중국어`, `사진 메뉴판` |
| 결제수단 | 예: `카드·현금, 알리페이 가능`, `확인불가` |
| 보유타이틀 | 공식 명단에서 확인한 타이틀과 연도, ` / `로 구분. 예: `착한가격업소(2025) / 백년가게(2021)`. 없으면 빈칸 |

### ② 탈락 목록
조사했지만 뺀 곳을 표로 적는다 (`이름 | 지역 | 탈락 이유`). 최소 10곳 이상. 검수자가 같은 곳을 다시 조사하지 않게 하기 위해서다.

### ③ 자체 점검
- 지역 × 트랙 개수표 (5×2)
- `확인불가`가 들어간 칸의 총 개수와 가장 많이 비는 항목
- 기존 목록 172곳과 겹치지 않는지 확인했다는 한 줄
- 타이틀별 후보 개수 (예: 착한가격업소 12곳, 백년가게 3곳)
