# 제주 오름 후보 수집 요청

너는 제주 여행 정보 사이트 jeju-live.com의 오름 정보 조사를 맡았다. 이용자는 중국·영어권 자유여행객이고, 대부분 20~30대 여성이며 **렌터카 없이** 택시·버스·대절 차량으로 다닌다. 이 정보는 한라산 페이지의 "오름" 탭에 15~20곳으로 소개된다. 너는 그 후보 **30곳**을 조사하고, 최종 선택은 사람이 한다.

결과는 사람이 검수한 뒤 사이트에 올린다. **많이 찾는 것보다 정확한 것이 중요하다.** 확인하지 못한 정보는 지어내지 말고 `확인불가`라고 적어라. 특히 통제(휴식년제) 정보가 틀리면 여행객이 헛걸음하므로 반드시 공식 출처로 확인하라.

### 작업 환경 규칙 (반드시 지킬 것)
- 이 작업은 **조사만** 한다. 저장소의 코드·데이터·설정 파일은 하나도 수정하거나 지우지 마라.
- 결과는 `directives/proposals/oreum_candidates.md` **한 파일에만** 쓴다.
- 웹페이지는 브라우저로 직접 열어서 확인하라. 검색 결과 요약만 보고 적지 마라.
- 10곳씩 세 번에 나눠 진행하고, 10곳마다 파일에 이어 붙인 뒤 "다음 10곳 진행할까요?"라고 묻고 멈춘다.

## 1. 후보 고르는 기준

아래 후보군에서 시작하되, 기준에 더 맞는 곳이 있으면 바꿔도 된다. 바꾼 경우 이유를 ③ 자체 점검에 적어라.

> 새별오름, 금오름, 다랑쉬오름, 아끈다랑쉬오름, 용눈이오름, 백약이오름, 따라비오름, 지미봉, 군산오름, 노꼬메오름, 거문오름, 물영아리오름, 사라봉, 도두봉, 서우봉, 산굼부리, 비양봉(비양도), 우도봉, 저지오름, 영주산, 고근산, 안돌오름, 밧돌오름, 송악산, 수월봉, 당산봉, 군산, 문도지오름, 큰노꼬메, 붉은오름

우선순위:
1. **쉬움**: 왕복 1시간 이내, 운동화로 갈 수 있음
2. **사진**: 억새·유채·일출·일몰·분화구·계단길 등 대표 장면이 있음
3. **접근성**: 렌터카 없이 택시나 버스로 갈 수 있음
4. **계절 분산**: 봄·여름·가을·겨울 각 계절에 추천할 곳이 최소 3곳씩 나오게
5. **지역 분산**: 아래 5개 지역마다 최소 3곳

| 코드 | 범위 |
|---|---|
| north | 제주시 동(洞) 지역 |
| east | 조천읍·구좌읍·성산읍·표선면·우도면 |
| west | 애월읍·한림읍·한경면·대정읍·안덕면 |
| south | 서귀포시 동(洞) 지역, 남원읍 |
| mid | 중산간 내륙 (교래·송당·가시리·서광 등) |

## 2. 반드시 확인할 것

- **통제 현황**: 자연휴식년제·탐방로 정비 등으로 출입이 막혔는지. 제주도청·제주시·서귀포시 공고나 비짓제주 공지에서 확인하고, 기간과 근거 URL을 적는다. 통제 중이어도 후보에서 빼지 말고 `통제현황`에 적어라 (사람이 판단한다).
- **예약제 여부**: 거문오름처럼 사전 예약이 필요한 곳은 예약 방법·인원 제한·휴무일을 적는다.
- **중국어 이름**: 비짓제주(visitjeju.net) 중문 페이지에 쓰인 공식 명칭을 그대로 적는다. 없으면 `확인불가`. 직접 번역하지 마라.

## 3. 정확성 규칙

- **링크를 지어내지 마라.** 실제로 열어서 확인한 URL만 적는다. 비짓제주 페이지가 있으면 반드시 포함한다.
- 소요시간·난이도는 여러 출처(비짓제주, 블로그 후기 3건 이상)를 보고 적는다. 출처마다 다르면 범위로 적는다 (예: `왕복 30~40분`).
- 택시 시간은 제주시청·서귀포 중문관광단지에서 출발하는 기준이다. 지도 서비스로 확인한 값만 적는다.
- 모든 행에 `확인일`(YYYY-MM-DD)을 적는다.

## 4. 출력 형식

결과는 마크다운 파일 하나에 아래 세 부분을 순서대로 담는다.

### ① 후보 CSV
코드 블록 하나에 담는다. UTF-8, 쉼표로 구분하고 모든 값은 큰따옴표로 감싼다. 헤더는 아래와 글자 하나까지 똑같이 쓴다.

```
"이름_ko","이름_zh","이름_en","지역","주소","위도","경도","높이_m","왕복시간","난이도","난이도근거","길형태","베스트시즌","일출일몰","사진포인트","통제현황","예약제","입장료","주차","화장실","택시_제주시청","택시_중문","버스","강풍주의","주의사항","비짓제주링크","출처링크","확인일"
```

| 칸 | 넣을 값 |
|---|---|
| 지역 | `north` `east` `west` `south` `mid` |
| 높이_m | 해발고도(표고) 숫자. 오름 자체의 높이(비고)를 알면 `난이도근거`에 함께 적는다 |
| 왕복시간 | 예: `왕복 30~40분` |
| 난이도 | `쉬움` / `보통` / `어려움` |
| 난이도근거 | 예: `정상까지 나무계단 약 300개, 경사 급함` |
| 길형태 | 예: `나무계단`, `야자매트 흙길`, `포장로` |
| 베스트시즌 | 예: `가을(억새 10~11월)`, `봄(유채 3~4월)`, `연중` — 여러 개면 ` / ` |
| 일출일몰 | `일출` / `일몰` / `둘다` / `없음` |
| 사진포인트 | 사진이 잘 나오는 장면 한 줄 |
| 통제현황 | `개방` / `휴식년 통제(2025-01~2026-12)` / `일부 구간 통제` + 근거 URL |
| 예약제 | `없음` 또는 예약 방법 요약 |
| 버스 | 가까운 정류장 이름, 대표 노선, 정류장에서 도보 시간. 사실상 어렵다면 `버스 접근 어려움` |
| 강풍주의 | `Y` / `N` (정상부가 트여 있어 바람이 강한 곳이면 Y) |
| 주의사항 | 예: `소·말 방목`, `일몰 후 조명 없음`, `비 온 뒤 미끄러움` |

### ② 탈락 목록
조사했지만 뺀 곳을 표로 적는다 (`이름 | 탈락 이유`).

### ③ 자체 점검
- 지역 × 계절 개수표
- `확인불가`가 들어간 칸의 총 개수와 가장 많이 비는 항목
- 통제 중이거나 예약제인 곳 목록
