# 제주 로컬 식당 이름 수집 (감자탕·족발·치킨·게장)

너는 제주 여행 정보 사이트 jeju-live.com의 식당 **이름 목록**을 모으는 일을 맡았다. 상세 정보는 필요 없다. 이름과 주소만 모으면, 사람이 공공데이터(일반음식점 인허가·착한가격업소 명단)와 대조해서 검증한다.

### 작업 환경 규칙 (반드시 지킬 것)
- 이 작업은 **조사만** 한다. 저장소의 코드·데이터·설정 파일은 하나도 수정하거나 지우지 마라.
- 결과는 `directives/proposals/restaurants_b_names.md` **한 파일에만** 쓴다.
- **웹페이지를 브라우저로 직접 열어서 확인한 곳만** 적는다. 기억이나 검색 결과 요약으로 적지 마라. 지난번 결과에서 링크와 ID가 지어낸 것으로 드러났다. 이번에는 링크·ID·리뷰 수·확인일을 **아예 적지 마라.**

## 찾을 것

메뉴 4종, 각 메뉴마다 **10곳씩, 총 40곳**:
1. 감자탕·뼈해장국
2. 족발·보쌈
3. 치킨·통닭 (시장 통닭, 옛날 통닭, 마늘 치킨 등)
4. 간장게장·양념게장

기준:
- 제주 사람들이 실제로 가는 동네 식당. 블로그·카페 후기에 "도민", "현지인", "단골" 맥락이 있는 곳.
- **제외**: 전국 프랜차이즈 지점(교촌, BHC, BBQ, 원할머니보쌈, 놀부, 이바돔 등), 호텔 식당, 최근 1년 안에 폐업 소식이 있는 곳.
- 지역이 한쪽에 몰리지 않게 제주시 동 지역, 서귀포 시내, 읍·면 지역을 섞는다.

## 출력 형식

코드 블록 하나에 CSV로 담는다. UTF-8, 모든 값은 큰따옴표로 감싼다. 헤더는 아래와 똑같이 쓴다.

```
"이름","메뉴","도로명주소","근거"
```

| 칸 | 넣을 값 |
|---|---|
| 이름 | 간판에 쓰인 상호 그대로. 지점이 있으면 지점명까지 |
| 메뉴 | `감자탕` / `족발` / `치킨` / `게장` 중 하나 |
| 도로명주소 | 확인한 도로명 주소 전체 (예: `제주특별자치도 제주시 서문로 9`). **모르면 이 곳은 적지 마라** |
| 근거 | 왜 로컬 식당이라고 판단했는지 한 줄 (예: `도민 단골 후기 다수, 시장 안 노포`) |

CSV 다음에 한 줄로 적는다: "직접 연 웹페이지 수: N개".
