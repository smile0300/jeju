# Gemini 프롬프트 — 추천 코스 장소 정보 점검 (Google Maps 활용)

> 용도: jeju-live.com 추천 코스(`src/data/courses.js`)에 들어간 58곳의 최신 정보를 모으는 읽기 전용 조사.
> 결과는 `directives/proposals/courses_gmaps.md`에 저장하고, Claude Code가 검증한 뒤 반영한다.
> 한 번에 다 시키면 답이 잘리므로 **1차(1~29) / 2차(30~58) / 3차(신규 후보)**로 나눠 입력한다.

## 3차 프롬프트 (신규 코스 후보)

```
이제 새 코스에 넣을 후보를 찾아줘. 이 사이트 이용자는 대부분 중국·영어권 20~30대 여성 관광객이고, 렌터카 없이 택시·버스로 다녀.

[조건]
- Google 지도 평점 4.3 이상, 리뷰 300개 이상, 현재 영업 중
- 위 58곳과 겹치지 않을 것
- 카페·포토존·자연 경관 위주 (술집·성인 시설 제외)
- 지역별(제주시·애월/한림·서귀포/중문·성산/구좌·남원/표선) 각 5곳씩, 총 25곳

[표 열]
지역 | 장소명 | 종류(카페/포토존/자연/체험) | 한 줄 소개 | 구글 평점(리뷰수) | 영업시간·휴무 | 가격대 | 버스 접근성(가까운 정류장) | 어울리는 계절 | Google 지도 링크

표 아래에 "이 후보들로 만들 만한 반나절 코스 3개"를 동선 순서대로 제안해줘.
```

## 받은 뒤 처리 (Claude Code)

1. 결과 전문을 `directives/proposals/courses_gmaps.md`에 붙여넣기
2. Claude Code가 `courses.js`의 `info`(ko/zh/en)와 대조 → 다른 항목만 비짓제주·공식 홈페이지로 재확인 후 반영
3. 신규 후보는 좌표를 비짓제주 API로 확인한 뒤 `STOP_POS`·`BLOCKS`에 추가
