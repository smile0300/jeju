# 2단계: 채택한 곳의 상세 정보 채우기

`research/approved_<지역>.csv`와 `research/approved_<지역>_rainy.csv`에 있는 곳만 조사해서, 사이트에 올릴 상세 정보를 CSV로 저장한다.
조사할 지역은 이 지시문을 실행한 사람이 알려준 값(east / west / south / north / mid)을 쓴다.

두 파일은 1단계 후보 목록에서 제주 거주자가 직접 고른 곳이다. 이름만 적힌 행이 있으면 거주자가 직접 추가한 곳이니 같은 방식으로 조사한다. **두 파일에 없는 곳을 새로 추가하지 않는다.** 비 오는 날 파일이 없으면 그 부분은 건너뛴다.

## 이 자료의 쓰임

중국인 개별 여행객에게 코스를 추천하고 예약을 대행하는 데 쓴다. 여행객은 이 정보만 보고 가게를 찾아가고, 운영자는 이 정보만 보고 예약을 넣는다. 그래서 **틀린 영업시간이나 휴무일 하나가 헛걸음으로 이어진다.** 확실하지 않은 값은 비워 두는 편이 낫다.

## 조사 규칙

1. 웹에서 직접 확인한 내용만 적는다. 확인하지 못한 칸은 비워 둔다. 추측으로 채우지 않는다.
2. 주소, 영업시간, 휴무일, 예약 수단, 가격은 네이버 지도(플레이스)를 먼저 보고, 가게의 공식 홈페이지나 인스타그램 공지와 다르면 **더 최근 것**을 쓰고 `메모`에 차이를 적는다.
3. 폐업·임시휴업·이전을 다시 확인한다. 해당하면 다른 칸은 비우고 `메모`에 `폐업`, `임시휴업`, `이전`이라고 적는다.
4. `이름_zh`는 샤오홍슈나 중국어 지도·후기에서 **실제로 쓰이는 표기**만 적는다. 찾지 못하면 비운다. 직접 번역해서 만들지 않는다.
5. 사진은 내려받지 않는다. `사진URL`은 비운다.
6. `research` 폴더 밖의 파일은 읽지도 고치지도 않는다. 결과 파일만 만든다.

## 출력

파일 두 개를 만든다. 둘 다 UTF-8이고 첫 줄은 아래 헤더 그대로다. 값에 쉼표가 있으면 큰따옴표로 감싼다.

- `research/places_<지역>.csv`: `approved_<지역>.csv`의 곳들 (예: `research/places_east.csv`)
- `research/places_<지역>_rainy.csv`: `approved_<지역>_rainy.csv`의 곳들

```
PlaceId,이름_ko,이름_zh,이름_en,지역,분류,주소_ko,위도,경도,권장체류분,영업시간,휴무일,예약필요,예약방법,입장료,실내외,사진URL,팁_ko,팁_zh,팁_en,추천이유,출처링크,최종확인일,공개,메모
```

| 칸 | 작성법 |
|---|---|
| PlaceId | 비운다 |
| 이름_ko | 네이버 지도에 등록된 이름 그대로 (택시 기사에게 보여 줄 이름) |
| 이름_en | 공식 영문 표기. 없으면 로마자 표기 |
| 지역 | east / west / south / north / mid |
| 분류 | 관광지 / 카페 / 식당 / 체험 / 쇼핑 / 시장 / 해변 / 박물관 |
| 주소_ko | 도로명 주소 |
| 위도, 경도 | 소수점 여섯 자리. 확인하지 못하면 비운다 |
| 권장체류분 | 숫자만. 식당 60~90, 카페 40~60, 관광지는 실제 관람 시간 |
| 영업시간 | `09:00~18:00`. 브레이크타임은 `11:00~15:00 / 17:00~21:00`처럼 나눠 적는다 |
| 휴무일 | `매주 월요일`, `연중무휴`, `매월 둘째·넷째 수요일` |
| 예약필요 | Y / N |
| 예약방법 | 네이버 예약, 캐치테이블, 전화, 현장 대기 등. 여러 개면 `/`로 구분 |
| 입장료 | 관광지·체험은 성인 요금. 식당·카페는 대표 메뉴와 가격 (예: `흑돼지 근고기 600g 66,000원`) |
| 실내외 | indoor / outdoor |
| 팁_ko, 팁_zh, 팁_en | 가서 도움이 되는 한 줄. 사진 명소라면 **어디서 무엇을 배경으로, 언제 찍으면 좋은지**를 먼저 적는다. 그 밖에는 덜 붐비는 시간, 꼭 시킬 메뉴 등. 세 언어 모두 같은 내용 |
| 추천이유 | 1단계의 `선정근거`를 옮기고, 새로 확인한 근거가 있으면 덧붙인다 |
| 출처링크 | 네이버 지도 플레이스 주소 |
| 최종확인일 | 조사한 날짜 (YYYY-MM-DD) |
| 공개 | N |
| 메모 | 아래 형식 |

### 메모 칸 형식

예약 대행에 필요한 정보를 아래 순서로, ` | `로 구분해서 적는다. 확인하지 못한 항목은 `불명`이라고 적는다.

```
우천:가능 | 사진:2층 창가에서 성산일출봉, 오전이 순광 | 전화:064-000-0000 | 외국인예약:어려움(네이버 예약은 한국 번호 인증 필요) | 예약금:1인 10,000원 | 예약가능시점:14일 전부터 | 최소인원:2 | 결제:카드·알리페이 | 중국어:메뉴판 있음 | 라스트오더:20:00 | 기타:노키즈존
```

| 항목 | 내용 |
|---|---|
| 우천 | 가능 / 불가. 비가 와도 그대로 즐길 수 있으면 `가능` |
| 사진 | 찍기 좋은 위치와 배경, 빛이 좋은 시간대. 사진 명소가 아니면 `없음` |
| 전화 | 예약에 쓰는 대표 번호 |
| 외국인예약 | 가능 / 어려움 / 불명, 그리고 이유 |
| 예약금 | 금액과 환불 조건. 없으면 `없음` |
| 예약가능시점 | 며칠 전부터 열리는지, 당일 예약이 되는지 |
| 최소인원 | 예약 가능한 최소·최대 인원 |
| 결제 | 알리페이·위챗페이·유니온페이 가능 여부, 현금만 받는지 |
| 중국어 | 중국어 메뉴판, 중국어 가능 직원 여부 |
| 라스트오더 | 식당·카페만 |
| 기타 | 노키즈존, 재료 소진 시 조기 마감, 반려동물, 계단만 있음 등 |

## 끝나면

아래 세 가지를 알려 준다.

1. 폐업·임시휴업·이전으로 확인된 곳
2. 네이버 지도와 공식 공지의 영업시간·휴무일이 달랐던 곳
3. 전화로 직접 확인해야 할 만큼 정보가 부족했던 곳
