## 1. 가장 큰 문제 — 이 페이지는 사용자를 밖으로 내보냅니다

카드의 실제 DOM입니다.

```html
<div class="festival-card"
     onclick="window.open('https://visitjeju.net/cn/festival/view?contentsid=...&menuId=undefined#p1','_blank')">
```

**카드를 누르면 새 탭으로 visitjeju.net으로 이탈합니다.**

즉 현재 이 페이지는 정보 서비스가 아니라 **Visit Jeju로 트래픽을 무료로 보내주는 링크 목록**입니다. 그 결과:

- 체류시간이 클릭 즉시 종료 → **재방문·전환 경로 없음**
- 상세 콘텐츠를 소유하지 않으므로 **SEO 자산이 쌓이지 않음** (링크주스가 외부로 유출)
- 微信 공유가 일어나도 **공유되는 건 visitjeju.net**
- 축제 → 예약/미식/날씨 등 **자사 기능으로 이어지는 동선이 원천 차단**

**"활성화"의 첫 번째 조건은 상세 페이지를 자체적으로 갖는 것입니다.** 지금 구조로는 트래픽이 늘어도 남는 게 없습니다.

> 덧붙여 URL에 **`menuId=undefined`** 가 그대로 들어가 있습니다. 코드 버그가 외부로 나가는 링크에 노출된 상태입니다.

### 2-5. 🟠 카드 면적의 80%가 정보를 전달하지 않습니다

카드는 **세로 포스터 이미지(480×679)** 가 대부분을 차지하는 구조인데, **포스터에 적힌 글자가 전부 한국어**입니다.

중국인 관광객에게 이 포스터는 정보가 아니라 **장식 이미지**입니다. 즉 카드 면적의 80%를 정보량 0인 요소에 쓰고, 정작 필요한 정보는 제목과 날짜 두 줄뿐입니다.

**카드에 없는 것**: 장소 · 카테고리 · 요금(무료/유료) · 실내/실외 · 예약 필요 여부 · 소요시간

Visit Jeju API는 주소·분류·태그를 제공하는데 **받아놓고 안 쓰고 있습니다.**

### 2-6. 🟠 이미지 실패 시 무관한 스톡 사진이 뜹니다

```html
onerror="this.src='https://images.unsplash.com/photo-1518005020251-...'"
```

이미지 로드 실패 시 **Unsplash 풍경 사진**으로 대체됩니다. 사용자는 그게 해당 행사 사진이라고 믿게 됩니다. **폴백이 아니라 오정보 생성**입니다.

### 2-7. 🟠 탐색 축이 "월" 하나뿐입니다

현재 필터: `기간 선택` + `8月~1月` 칩 6개.

없는 축: **카테고리**(전시/공연/팝업/체험/야시장) · **지역**(제주시/서귀포/동/서) · **요금** · **실내/실외** · **오늘 열리는 것**

94건을 월 하나로 걸러도 여전히 수십 건이라 **필터가 필터 역할을 못 합니다.**

### 2-8. 🟠 '축제'와 '상설 프로그램'이 섞여 있습니다

`2026.01.01 ~ 12.31`, `2026.03.20 ~ 10.09` 처럼 **연중 상시 운영**인 항목이 다수입니다. 이건 축제가 아니라 상설 전시·시설·프로그램입니다.

기간 한정 이벤트와 연중 상설을 같은 목록에 두면 **"지금 아니면 못 본다"는 긴급성이 사라집니다.** 축제 페이지의 동력은 긴급성인데 그게 희석돼 있습니다.

## 3. 해결 방안

### 3-1. ★ 콘텐츠 큐레이션 — 94건을 걸러냅니다 (최우선)

**자동 필터 규칙**

```js
// 제외 규칙 — 관광객 참여 불가/무의미
const EXCLUDE = [
  /지원사업|공모|모집\s*안내|캠페인|공개강좌|워크숍|수업|교육|세미나/,
  /참여자\s*모집|신청\s*접수|설명회|간담회/,
];

// 한국어 능력 필수 → 제외 또는 하위 노출
const KOREAN_REQUIRED = /강좌|낭독|독서|글쓰기|인문학|토크|해설/;

// 가산 — 언어 장벽 없는 체험형
const BOOST_IP   = /지브리|吉卜力|海贼王|원피스|팝업|快闪|스투시|디즈니|산리오/;
const BOOST_TYPE = /전시|展|공연|演出|불꽃|야시장|夜市|축제|节|분수|喷泉|야간개장|夜间/;

function touristScore(item) {
  const t = item.title + ' ' + (item.tags || '');
  if (EXCLUDE.some(r => r.test(t))) return -1;        // 목록에서 제외
  let s = 50;
  if (BOOST_IP.test(t))   s += 40;
  if (BOOST_TYPE.test(t)) s += 20;
  if (KOREAN_REQUIRED.test(t)) s -= 30;
  if (item.isFree)        s += 10;
  if (item.durationDays > 300) s -= 20;               // 상설은 별도 탭으로
  return s;
}
```

**수동 큐레이션 병행**: 자동 규칙으로 1차 정리 후, **주 1회 운영자가 상위 10~15건을 손으로 확정**하세요. 94건을 관리하는 것보다 **15건을 잘 관리하는 게 훨씬 효과적**입니다.

## 6. 총평

축제 페이지는 **콘텐츠가 부족한 게 아니라 과잉입니다.** 94건 안에 지브리 전시, 원피스 전시, 스투시 팝업, 좀비 트레인처럼 **중국인 관광객에게 단독으로 방문 동기가 되는 IP 콘텐츠가 이미 들어 있는데**, 학부모 심리수업·지자체 지원사업 공고와 같은 크기로 나열되어 묻혀 있습니다.

활성화의 순서는 이렇습니다.

1. **걸러내기** — 94건 → 큐레이션 15건. 개발 반나절
2. **지금 기준으로 정렬** — 작년 12월 시작 행사가 최상단인 상태부터 해결
3. **밖으로 내보내지 않기** — 자체 상세 페이지 없이는 트래픽이 늘어도 남는 게 없습니다

특히 **3번이 이 페이지의 근본 문제**입니다. 지금 구조에서는 이 페이지가 잘 될수록 Visit Jeju가 이득을 봅니다. 상세 페이지를 자체적으로 갖는 순간, 축제는 **날씨·예약·미식·공항을 잇는 허브**가 될 수 있습니다 — 그 조합을 가진 사업자는 흔치 않습니다.
